# Vibe Coding Showcase

A collection of mini mobile apps and prototypes built with **AI-assisted development** tools. Each project demonstrates rapid prototyping with vibe coding.

## What is Vibe Coding?

Vibe coding is a development style where you leverage AI tools to move fast, ship ideas quickly, and iterate rapidly. Instead of writing every line manually, you collaborate with AI to build working products at speed.

## Projects

| Project | Description | Tech | AI Tool |
|---------|-------------|------|---------|
| Quote of the Day | A daily motivational quote app with sharing feature | Flutter | Cursor |
| Weather Widget | Minimal weather app with location support | Flutter + OpenWeather API | Claude |
| Pomodore Timer | Focus timer with session tracking | Flutter | Gemini |
| QR Scanner | QR code scanner & generator | Flutter | Cursor |

## AI Tools Used

- **Cursor** - AI-powered IDE
- **Claude** (Anthropic) - code generation & refactoring
- **Gemini** - Google AI for rapid prototyping
- **ChatGPT** - architecture planning

## Key Lessons

1. AI is a multiplier, not a replacement - understanding the code still matters
2. Start with a clear prompt - specificity leads to better outputs:3. Iterate fast - ship a working version, then refine
4. Review AI-generated code carefully - AI can hallucinate

## Getting Started

Each project is in its own folder. Navigate to any project and:

```bash
cd project-name
flutter pub get
flutter run
```
